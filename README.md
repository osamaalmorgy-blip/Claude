# سجل التاسكات اليومية — Layup & Bagging Log

موقع من صفحة واحدة (`index.html`) لتسجيل التاسكات اليومية وتصديرها كنص حسب فترة زمنية محددة.
يعمل بدون إنترنت وبدون سيرفر، وتُحفظ البيانات محلياً في المتصفح (localStorage).

## الاستخدام
افتح `index.html` في المتصفح مباشرة، أو ارفعه على أي استضافة ثابتة (GitHub Pages مثلاً).

## المميزات
- **تسجيل تاسك:** رقم قطعة وأمر شغل (مع إمكانية إضافة أكثر من رقم للتاسك الواحد)، نوع العمل
  (Layers من/إلى · Final bag · Rebag · أخرى)، التاريخ، وقت البدء والانتهاء، وملاحظة اختيارية
  مثل `(Quality delay)` أو `Hold by Quality`.
- **السجل:** مجموعات حسب اليوم مع اسم اليوم وإجمالي ساعاته وعدد تاسكاته، بحث برقم القطعة أو
  أمر الشغل أو الملاحظة، وأزرار تعديل / تكرار / حذف لكل تاسك، وزر «حذف كل السجل» بجانب البحث (يظهر فقط عند وجود تاسكات ويطلب تأكيداً).
- **التصدير:** تحديد «من تاريخ / إلى تاريخ» أو اختصارات (اليوم · آخر ٧ أيام · هذا الشهر ·
  الشهر الماضي · الكل)، معاينة فورية للنص، نسخ بضغطة، أو تنزيل ملف `.txt`.
- **الاستيراد الذكي:** الصق أي قائمة مكتوبة وسيقسّمها إلى نفس بنية التاسك، مع معاينة مباشرة
  لما سيُستورد قبل تأكيده. يفهم:
  - وجود سطر فاصل بين التاسكات أو عدمه (يكتشف بداية كل تاسك بنفسه)
  - أسماء الحقول الكاملة والمختصرة: `Part number` / `P/N`، `Work order` / `W/O`،
    `Layers` / `Layer` / `Ply`، `Final bag` / `FB`، `Rebag`، وما يقابلها بالعربية
    (رقم القطعة، أمر الشغل، الطبقات، التاريخ، البداية، النهاية)
  - النقطتين اختيارية: `Date: 6-7-2026` و `date 6-7-2026` سواء
  - التواريخ: `6-7-2026` · `6/7/2026` · `6.7.2026` · `2026-07-06` · `6 July 2026`
  - الأوقات: `15:00` · `15.00` · `1500` · `3:00 pm` · `6:15`، وتُوحَّد إلى `HH:MM`
  - الأرقام العربية (٠١٢٣…) تُحوَّل تلقائياً
  - أكثر من حقل في سطر واحد: `Start 15:00 Stop:20:30`
  - أكثر من رقم قطعة في التاسك الواحد، وسطر المدى بدون كلمة Layers مثل `11.3 to final bag`
  - الأسطر غير المعروفة تُعتبر ملاحظات (مثل `Hold by Quality`)، والعناوين الزائدة تُتجاهل وتُعرض لك
  - التاسكات المكرّرة (الموجودة أصلاً في السجل) تُكتشف ولا تُضاف مرتين
  - التاسك بدون تاريخ يُستورد ويظهر في مجموعة «بدون تاريخ» في أعلى السجل، ولا يدخل التصدير
    حتى تضيف له تاريخاً
  - أسطر فارغة داخل التاسك نفسه (لا تُعتبر فاصلاً؛ الفصل يعتمد على المحتوى)
  - حقول البداية والنهاية بأي تسمية: `Start Time` · `Finish time` · `Finished time` · `End`
  - حدود الطبقات في سطرين منفصلين: `Start layer: 1.1` و `Finish layer:`،
    و`From layer: 5.1 to 10.1`، و`Till layer 4.11` (نهاية فقط → `Layers: to 4.11`)
  - عدد الطبقات بدل المدى: `Layers: 10`
  - النص بعد فاصلة في سطر الطبقات ينزل ملاحظة: `Layer: 12.1 to 19.8, didn't found ports`
  - التنسيق العربي المنقّط: `* التاريخ:` · `* رقم البارت (153302919):` · `* رقم أمر العمل (003255):`
    · `* بداية العمل من الـ Ply:1.1` · `* نهاية العمل عند الـ Ply:4.1`
  - `* اسم: ...` يُعتبر بداية تاسك جديد ويُتجاهل، ومثله `رقم آخر Ply:`
  - أرقام قطع غير رقمية مثل `26-1653-001`
- **تحليل بواسطة Claude — بدون مفتاح:** زر «انسخ الطلب وافتح Claude» ينسخ نصك مع تعليمات
  التنسيق ويفتح claude.ai في تبويب جديد؛ تلصق، وتنسخ رد Claude، وتلصقه في مربع الاستيراد
  فيقرأه المحلّل المحلي مباشرة. يعمل باشتراك Claude العادي بلا مفتاح ولا تكلفة إضافية.
- **تحليل تلقائي بمفتاح API (اختياري):** زر يرسل النص الملصوق إلى
  Messages API ليقسّمه Claude دون مغادرة الصفحة، ثم تُعرض النتيجة في نفس المعاينة قبل الإضافة.
  - يحتاج مفتاح Anthropic API خاص بك، يُحفظ في `localStorage` لهذا المتصفح فقط ولا يُرفع لأي مكان
  - الموديل الافتراضي `claude-opus-5` مع بديل `claude-sonnet-5` الأسرع والأقل تكلفة
  - يستخدم structured outputs (`output_config.format`) فتأتي النتيجة بنفس بنية التاسك مباشرة
  - التحليل المحلي يظل هو الافتراضي (مجاني وفوري ويعمل بدون إنترنت)؛ Claude للنصوص الغريبة فقط
  - التحليل من داخل صفحة الـ Artifact محجوب شبكياً، فاستخدم رابط GitHub Pages لهذه الميزة

- **نسخة احتياطية:** تصدير/استعادة كل السجل كملف JSON.
- وضع ليلي/نهاري، وواجهة عربية تعمل على الجوال.

## صيغة التصدير
```
Part number: 153302779
Work order: 002866
Layers: From 7.1 to 13.4
Date: 6-7-2026
Start 15:00
Stop:20:30
```
تُفصل التاسكات بسطر فارغ، وتُرتّب تصاعدياً حسب التاريخ ثم وقت البدء.

## ملاحظة
البيانات محفوظة في متصفح الجهاز نفسه فقط، لذلك خذ نسخة احتياطية JSON بين فترة وأخرى،
أو عند تغيير الجهاز/المتصفح.
