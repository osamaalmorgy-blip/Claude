# سجل التاسكات اليومية — Layup & Bagging Log

موقع من صفحة واحدة (`index.html`) لتسجيل التاسكات اليومية وتصديرها كنص حسب فترة زمنية محددة.
يعمل بدون إنترنت وبدون سيرفر، وتُحفظ البيانات محلياً في المتصفح (localStorage).

## الاستخدام
افتح `index.html` في المتصفح مباشرة، أو ارفعه على أي استضافة ثابتة (GitHub Pages مثلاً).

## المميزات
- **تسجيل تاسك:** رقم قطعة وأمر شغل (مع إمكانية إضافة أكثر من رقم للتاسك الواحد)، نوع العمل
  (Layers من/إلى · Final bag · Rebag · أخرى)، التاريخ، وقت البدء والانتهاء، وملاحظة اختيارية
  مثل `(Quality delay)` أو `Hold by Quality`.
- **السجل:** مجموعات حسب اليوم مع اسم اليوم وإجمالي ساعاته وعدد تاسكاته، بحث برقم القطعة أو
  أمر الشغل أو الملاحظة، وأزرار تعديل / تكرار / حذف لكل تاسك.
- **التصدير:** تحديد «من تاريخ / إلى تاريخ» أو اختصارات (اليوم · آخر ٧ أيام · هذا الشهر ·
  الشهر الماضي · الكل)، معاينة فورية للنص، نسخ بضغطة، أو تنزيل ملف `.txt`.
- **الاستيراد:** لصق قائمة مكتوبة بالصيغة المعتادة (كل تاسك يفصله سطر فارغ) وتحويلها إلى
  سجلات قابلة للتعديل — يتعرّف على `Part number` و `Work order` و `Layers/Layer` و `Final bag`
  و `Rebag` و `Date` بصيغة `يوم-شهر-سنة` و `Start` و `Stop`، وأي سطر آخر يُعتبر ملاحظة.
- **نسخة احتياطية:** تصدير/استعادة كل السجل كملف JSON.
- وضع ليلي/نهاري، وواجهة عربية تعمل على الجوال.

## صيغة التصدير
```
Part number: 153302779
Work order: 002866
Layers: From 7.1 to 13.4
Date: 6-7-2026
Start 15:00
Stop:20:30
```
تُفصل التاسكات بسطر فارغ، وتُرتّب تصاعدياً حسب التاريخ ثم وقت البدء.

## ملاحظة
البيانات محفوظة في متصفح الجهاز نفسه فقط، لذلك خذ نسخة احتياطية JSON بين فترة وأخرى،
أو عند تغيير الجهاز/المتصفح.
